# Student Record Management System

A menu-driven **Student Record Management System developed in C** for managing student information efficiently.

## Features

* Add new student records
* Display all student records
* Delete records by roll number or name
* Modify records by roll number, name, or percentage
* Save student data to a file
* Sort records by name, roll number, or percentage
* Reverse student records
* Delete all records
* Save and exit or exit without saving

## Technologies

* **Language:** C
* **Concepts:** Structures, Functions, Pointers, Arrays, Strings, File Handling, Searching, Sorting, Loops, and Switch Case

## Main Menu

```text
A/a : Add Student
D/d : Delete Student
S/s : Show All Students
M/m : Modify Student
V/v : Save Data
E/e : Save & Exit
T/t : Sort Records
L/l : Delete All Records
R/r : Reverse Records
```
